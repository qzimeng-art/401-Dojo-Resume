# Responsive and Accessibility Requirements

Web must work from phone to desktop. The form collapses to one column; the board may scroll horizontally; modals stay within the viewport and scroll internally. Fixed actions must not obscure controls.

Use semantic headings, form labels, meaningful action text, keyboard operation, visible focus, sufficient contrast, and descriptive errors. Icon-only controls need accessible names.

Mobile must respect safe areas, theme contrast, roughly 44×44 point targets, software keyboards, and loading/empty/error states. This is a continuing requirement, not a claim that every existing screen has passed an audit.
