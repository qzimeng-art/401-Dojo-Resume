# Demo and Local Data

`/demo` uses `frontend/src/pages/Dashboard/sampleData.js`, with representative applications across all four statuses and sample attachment metadata. It is client-side and non-persistent.

Demo records must remain fictional, varied, and publishable. Include company, position, status, date, optional notes/requirements/URL, and optional files.

The checked-in SQLite database is development data, not a production seed contract. Tests create their own records. Never put real credentials, resumes, or production user data in samples or fixtures.
