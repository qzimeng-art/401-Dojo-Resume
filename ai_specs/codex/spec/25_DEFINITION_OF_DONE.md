# Definition of Done

A change is done when behavior matches JobTrackerr! and the requested scope; owner isolation remains intact; validation/loading/empty/error states work; web is responsive and keyboard-usable; mobile respects safe areas/theme; demo does not persist fictional/private data; relevant tests/lint/build pass; contract docs are updated; and no secrets, uploads, or production data are committed.

Roadmap concepts are not completion requirements unless explicitly scoped in.
