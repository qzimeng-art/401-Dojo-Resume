# Definition of Done

## Product-wide

Done means:
- all routes exist
- navigation works
- database persists
- seed data works
- deployment build works
- mobile works
- no core crash states
- copy is consistent
- no raw placeholder text

## Applications

Done when:
- create
- edit
- delete
- search
- filter
- sort
- status update
- board/list
all work.

## Detail

Done when:
- all metadata visible
- next action manageable
- job description visible
- resume card visible
- communication works
- timeline works

## Resume

Done when:
- master editable
- preview works
- print works
- tailored copy created
- tailored edits isolated

## Match Studio

Done when:
- job description analyzed
- score shown
- matched shown
- missing shown
- suggestions shown
- no API required
- tests cover scoring

## Dashboard

Done when:
- metrics correct
- funnel correct
- conversion rates correct
- recent activity present
- stale items present
- needs attention present

## Today

Done when:
- overdue
- due today
- stale
- interview-priority
are prioritized and linked.

## UX

Done when:
- empty states
- loading states
- errors
- toasts
- confirmations
exist.

## Mobile

Done when at 375px:
- nav usable
- create application usable
- detail usable
- communication usable
- resume usable
- Today usable

## Quality

Done when:
- typecheck passes
- build passes
- tests pass
- no obvious console errors on core path
