# Dashboard and Counts

The dashboard shows an add action, total count, Applied/Interview/Offer/Rejected counts, search, and board/list switching. Counts are computed in the browser from filtered applications, so search changes the totals.

It does not calculate response rate, conversion, time-to-response, stale applications, trends, or charts. These are not implemented analytics.

Authenticated mode fetches API data. Demo mode uses local samples and must not persist them.
