# Resume Matching — Roadmap Only

Resume-match scoring is not implemented and is not part of the current contract.

Applications store free-text `job_requirements`, and users may upload application files plus a master resume, but the system does not parse documents, extract keywords, calculate coverage, call AI, or suggest tailoring.

Do not advertise or add matching incidentally. Future work requires explicit approval, privacy handling, API/model changes, deterministic tests, and clear limitations.
