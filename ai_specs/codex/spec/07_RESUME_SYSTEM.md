# Resume and Supporting Files

The project has file attachments, not a resume authoring system.

Users may attach PDF, DOC/DOCX, TXT, or other files to an application. The web client labels common extensions and uploads each file as multipart data after saving its parent. The backend stores the original filename, type label, and file path.

There is no master resume, structured editor, PDF generator, tailored copy, or resume-version table. Such work is future scope requiring an approved design and migration.
