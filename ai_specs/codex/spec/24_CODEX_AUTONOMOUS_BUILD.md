# Coding-Agent Work Contract

1. Read the master and relevant topic spec.
2. Inspect implementation first; code and migrations outrank stale prose.
3. Preserve React/Vite + Expo + Django REST unless explicitly replacing it.
4. Keep API records owner-scoped and owner assignment server-controlled.
5. Keep demo data separate from authenticated persistence.
6. Do not invent ApplyFlow, Next.js/Supabase, resume matching, Today, or timelines.
7. Make the smallest coherent change across affected layers.
8. Add tests for backend behavior and security boundaries.
9. Run proportional Django, web, and mobile verification.
10. Update specs/docs when contracts change.

For an approved roadmap feature, define data/API/UX/privacy against the current architecture rather than copying obsolete specs.
