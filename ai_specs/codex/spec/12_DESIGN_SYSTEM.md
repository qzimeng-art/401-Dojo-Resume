# Design System

JobTrackerr! uses a light slate/white web interface, blue-to-indigo accents, rounded cards/modals, subtle borders/shadows, and Lucide icons. Status colors distinguish Applied, Interview, Offer, and Rejected, though exact hues currently differ between clients.

Web uses Tailwind CSS 4 and responsive breakpoints. Mobile uses React Native `StyleSheet` plus a light/dark theme context.

Preserve the `JobTrackerr!` wordmark, accessible contrast, visible web focus, clear states, and adequate mobile touch targets. Do not introduce Next.js/shadcn conventions into this codebase.
