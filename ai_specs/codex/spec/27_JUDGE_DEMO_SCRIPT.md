# Current Project Demo Script

## 1. Identity and problem

“This is our 401 Dojo project, JobTrackerr! Job searches become hard to manage across spreadsheets, notes, and folders, so we created one private workspace for applications and supporting files.”

## 2. Preview

Open `/demo`. Show the unsaved-data banner, four statuses, counts, search, and board/list switch.

## 3. Authentication

Show signup/login and mention Google sign-in, then enter the protected dashboard. Explain that web and mobile share an owner-scoped API.

## 4. Workflow

Add an application with company, role, URL, date, requirements, notes, and a sample document. Search for it, switch views, edit status to Interview, and show changed counts. Open the profile and show the master-resume upload/display flow. Demonstrate delete confirmation only if safe.

## 5. Mobile

Show the Expo dashboard and searchable list, edit an application, and refresh.

## 6. Close

“JobTrackerr! delivers secure accounts, application CRUD, status visibility, supporting files, master-resume storage, a public demo, and shared web/mobile access.”

Do not claim AI matching, automated reminders, Today, or communication history.
