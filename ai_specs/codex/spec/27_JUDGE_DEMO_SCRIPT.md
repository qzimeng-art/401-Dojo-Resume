# Judge Demo Script

## Target length

3–4 minutes.

## Opening

> “Applying to jobs gets messy fast: different stages, follow-ups, recruiter messages, and different resume versions. ApplyFlow turns all of that into one command center.”

Open Dashboard.

## Dashboard

Show:
- total applications
- interviews
- follow-ups due
- funnel
- Needs Attention

Say:

> “Instead of opening every application, I can immediately see what needs attention and where my search is converting.”

## Applications

Open board.

Search/filter quickly.

Say:

> “Every application is organized by stage, and I can see follow-ups and resume status directly from the board.”

Open Shopify.

## Application detail

Point out:
- status
- next action
- job description
- timeline

Say:

> “All the job context, recruiter communication, and status history stays attached to the application.”

## Resume wow moment

Click tailored resume.

Say:

> “This version started from my master resume, so I never rebuild from scratch.”

Show Match Studio.

> “ApplyFlow compares the job description with this tailored copy and gives an explainable keyword-coverage score, showing what is already covered and what may be worth emphasizing.”

Point to matched/missing terms.

## Response tracking

Back to application.

Show/log interview invitation.

Move status if needed.

Point at timeline.

> “The timeline keeps recruiter communication and state changes together, so I can see the full history.”

## Today

Open Today.

> “And instead of manually checking everything, Today prioritizes overdue follow-ups, stale applications, and interview-related actions.”

## Mobile

Resize or use mobile tab.

> “The same core workflow remains usable on mobile.”

## Close

> “We focused on making the required organizer complete, then used the same data to make the job search smarter: resume alignment, application analytics, follow-up prioritization, and a unified history.”

## Judge questions

### Does the match score use AI?
> “The core score is deterministic and explainable, so it works reliably without any external API. AI rewriting can be layered on later, but the product never depends on it.”

### Why no email sync?
> “The challenge is about organizing applications and responses. We prioritized a stable end-to-end workflow and modeled communication cleanly so integrations can be added later without being required for the core experience.”

### Is it multi-user?
> “The hackathon brief does not require job-poster user management, so we intentionally focused on the job seeker workflow and polish rather than auth infrastructure.”

### What would you build next?
> “Inbox and calendar integrations are the natural next step because communications and next actions are already first-class data in the product.”
