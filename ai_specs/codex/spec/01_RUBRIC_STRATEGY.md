# Project and Evaluation Strategy

JobTrackerr! gives job seekers one private place to record opportunities, see pipeline status, keep supporting documents, and update progress from web or mobile.

Strongest implemented evidence:

1. Shared Django API for web and mobile.
2. Email/password and Google authentication.
3. Per-user application/file isolation.
4. Complete application CRUD.
5. Board/list views, search, and status counts.
6. Per-application attachments plus a profile-level master-resume upload.
7. Public demo and moderated reviews.
8. Responsive web plus Expo mobile companion.

Do not claim resume generation, AI matching, automated reminders, or communication tracking; those are not implemented.
