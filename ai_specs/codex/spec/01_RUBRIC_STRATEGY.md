# Rubric Strategy

## Evaluation objective

Every explicit judging category must have:
- at least one obvious baseline feature,
- at least one polished visual surface,
- one judge-visible “proof” moment.

## 1. Tracking Applications

### Baseline
- application CRUD
- status/stage
- date applied
- company/position
- filters
- search

### Proof moment
Move one application from Applied → Interview and show dashboard metrics update.

### Extra polish
- Kanban stage columns
- next-action badge
- stale indicator

---

## 2. Master Resume & Customization

### Baseline
- persistent master resume
- create job-specific tailored copy
- edit tailored resume independently

### Proof moment
Open a tailored resume beside Match Studio and show missing keywords.

### Extra polish
- formatted resume preview
- last-updated timestamp
- source label: “Based on Master Resume”

---

## 3. Response Management

### Baseline
- log employer communication
- capture interview/rejection/offer
- view communication history

### Proof moment
Log an interview invitation and show it appear in the timeline.

### Extra polish
- quick event buttons
- timeline icons
- status transition event alongside communication

---

## 4. Ease of Use

### Baseline
- obvious navigation
- low-click workflows
- clear primary actions

### Proof moment
Add an application in under 30 seconds without explaining fields.

### Extra polish
- intelligent defaults
- persistent Add Application button
- helpful empty states

---

## 5. Accessibility

### Baseline
- usable on mobile
- semantic labels
- keyboard focus

### Proof moment
Resize to mobile and use core flow.

### Extra polish
- visible focus ring
- status always has text
- no hover-only actions

---

## 6. Visual Design

### Baseline
- consistent layout
- professional components
- readable hierarchy

### Proof moment
Dashboard looks like a real SaaS product at first glance.

### Extra polish
- empty/loading states
- charts
- responsive card layouts
- subtle interactions

---

## 7. Creativity

### Baseline
Required app behaves reliably.

### Differentiators
1. Resume Match Studio
2. Today Queue
3. Application Intelligence
4. Unified Activity Timeline

### Best creativity story

> “We didn’t bolt on unrelated AI. We made the required workflow smarter using the data the organizer already owns.”

That is the product narrative.
