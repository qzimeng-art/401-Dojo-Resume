# Exact Screen Specifications

## Screen 1 — Dashboard

### First viewport
- page title + Add application
- 5 KPI cards
- application funnel
- needs attention

### Lower viewport
- conversion metrics
- recent activity
- stale applications

### First impression target
Judge understands in under 5 seconds:
- this tracks applications
- it has workflow intelligence

---

## Screen 2 — Applications Board

### First viewport
- header
- search/filter toolbar
- 5 Kanban columns

Cards visible immediately.

### Required visual details
- status column count
- next action
- resume indicator
- stale/overdue indicator

---

## Screen 3 — Applications List

Desktop table.
Mobile cards.

Use for judge if board is visually crowded.

---

## Screen 4 — Add Application

Recommended as right-side sheet on desktop and full-height sheet on mobile.

Buttons:
- Cancel
- Add application

---

## Screen 5 — Application Detail

Must be one of the most polished screens.

Header + status + quick actions.
Overview and job description left.
Timeline right.
Resume card lower-left.

---

## Screen 6 — Master Resume

Two modes:
- Edit
- Preview

Use tabs or segmented switch.

---

## Screen 7 — Tailored Resume

Desktop:
left 65–70% editor
right 30–35% Match Studio

Mobile:
Match Studio summary first, editor below.

---

## Screen 8 — Today

Priority queue.
No chart.
Action-oriented.

---

## Screen 9 — Settings

Small.

Fields:
- Stale after: 10 days
- Display name

No complex settings system.

---

## Modal / Sheet — Log Communication

Compact.
Should fit on laptop without scrolling excessively.

---

## Modal / Sheet — Set Follow-up

Fields:
- action text
- date/time

Quick chips:
- Tomorrow
- In 3 days
- Next week

Implement quick chips only if trivial.

---

## Toasts

Success examples:
- `Application added`
- `Status updated`
- `Communication logged`
- `Follow-up scheduled`
- `Master resume saved`
- `Tailored resume saved`

Error:
- `Something went wrong. Please try again.`

Where useful, include specific validation instead.
