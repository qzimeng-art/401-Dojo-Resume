# Screen Specifications

## Web

Home presents value, features, testimonials, calls to action, and mobile promotion. Login/signup share an auth layout. About, Contact, Support, Security, Privacy, and Terms provide supporting content. Unknown URLs render Not Found.

Dashboard contains brand/search/account header, verification banner when applicable, summary counts, view controls, board/list results, profile mode, application modal, master-resume upload modal, and review modal. Profile/dashboard surfaces display the newest uploaded master resume. Demo adds an unsaved-data banner and signup CTA.

## Mobile

Welcome, Login, and Signup cover entry. Dashboard shows summary/recent applications and account/theme actions. Application List offers search, refresh, badges, and edit-modal access.

There are no resume-editor, match, Today, or application-detail routes.
